# Honor Duo One 1.1.14（174）

## 功能添加

- **信号点间距**：基础外观 →「布局」，默认 100%，可调 60–200%。同时放大/收拢环外信号的列间距与环内信号点的角度间距；超过 100% 时环内珠排最多铺到开口能容下的宽度。
- **信号条粗细**：基础外观 →「布局」，默认 100%，可调 40–200%。同时改变环外信号柱的宽度与信号点的直径；柱宽超过列距时相邻两柱会重叠，这是允许的。
- **开口按文字测量**：基础外观，默认关闭（沿用固定开口）。打开后，圆环顶部开口的宽度按实际顶部文字的墨迹宽度换算，字宽就宽口、字窄就窄口；只影响顶部开口，底部开口不变。
- **中部以圆心为准**：基础外观，默认关闭（沿用比圆心低约 2.5 个单位的槽心）。打开后圆环中间一档的内容与圆环自身圆心对齐。
- **开口读数内缩**：基础外观，默认关闭。打开后开口里的读数两端各让出半个体部线宽，避免贴住圆环端帽；只作用于顶部和底部开口，中间一档不变。
- **环内信号平铺**：移动信号，默认关闭（沿弧）。打开后环内信号点排成水平直线而不是沿圆弧弯折；只影响环内，不影响环外读数。
- **行距跟随点径**：移动信号，默认关闭（沿用写死的行距）。打开后环内两排信号点的行距由点径和「信号点间距」推算，点放大或间距拉开时两排会同步让开。
- **5GA 显示为 5A**：网络类型，默认关闭（保持 5GA）。打开后环内、环外与双排读数里的「5GA」都显示为「5A」；只改显示，不影响网络识别。
- **时钟按墨迹居中**：时钟日期，默认关闭（按字体整体度量居中）。打开后胶囊与矩形布局里的时钟按这一串字的实际墨迹居中，数字的上下留白更均匀。
- **显示碰撞盒**：基础外观，默认关闭。打开后用洋红方框标出模块在宿主里实际占用的矩形与中线，用来核对灵动胶囊展开时的让位判定与异形屏裁切；仅调试用。
- **冲突提示**：关于页新增「模块冲突」一项，默认关闭。打开后列出已安装的同类状态栏模块（HonorDuo、HyperDuo、HonorDuoBar 等）；只能判断「已安装」，请据此核对是否只保留一个模块作用于「系统界面」。

## 功能修复

- **打开设置退回桌面**：此前版本点桌面图标打开本模块设置会立刻退回桌面，本版恢复正常；已保存的设置全部保留。
- **息屏显示电池**：熄屏显示里的电池图标与电量此前偶尔缺失，锁屏后放置一段时间、或息屏时插拔充电最明显；本版恢复稳定显示。

## 功能变更

- **图标整体尺寸上限 130%**：基础外观 →「整体尺寸」，滑块上限由 100% 放到 130%。超过 100% 时字形会画得比宿主给的框更大，可能挤到相邻图标，由宿主自行排布；默认仍是 100%，视觉不变。
- **圆环线宽上限 20**：圆环线宽滑块上限由 16 放到 20，默认值与当前绘制不变。线宽到顶时环内信号点不再继续放大，而是停在能容纳的尺寸，避免溢出。
