# Honor Duo One 1.1.13（172）

## 功能添加

- **息屏时使用原生状态栏**：排布 →「功能开关」，默认开启，即息屏显示系统原生状态栏、亮屏瞬间切回三合一。关闭后息屏也绘制本模块状态栏，亮屏时不再有切换感；关闭前会弹窗确认，因为息屏（AOD）下将没有电池电量图标。
- **赞赏码**：关于页 Trae 邀请链接下方新增入口，点开显示赞赏码大图。本软件完全免费，所有功能都不收费；赞赏完全自愿、金额随意，不会解锁或限制任何功能。

## 功能修复

- **环形电量显示更准**：环上进度按圆弧端点的实际可见长度换算，50% 时右半弧不再多出一个圆点，74% 时右半弧也不会看起来超过一半。
- **防烧屏微移不再裁角**：开启智能防烧屏后，字形移到容器边缘时不再被裁平；父容器的裁剪判定留出位移余量，并按窗口位置判断字形是否真的完整可见。

---

**安装**：覆盖安装即可，设置全部保留。
